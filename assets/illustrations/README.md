# Original welcome artwork

`welcome.png` was generated with the built-in image-generation tool for this
project, then copied into this directory. `assets/icons/deep-purge-ultra.svg`
is the original editable application mark. The interface falls back to symbolic
icons if optional artwork cannot be loaded.

## Generation prompt

Use case: stylized-concept. Asset type: original decorative welcome illustration
for DeepPurge Ultra, a premium native Linux application uninstaller. Create a
restrained 3D editorial illustration of three floating rounded translucent blue
and violet software cubes gently separating above a soft circular violet light
pool, a small four-point sparkle suggesting clarity and order. Deep charcoal
background exactly close to #13151d, subtle cool lighting, generous empty
negative space, centered composition, crisp premium rendering, no words, no
letters, no UI, no brand logos, no watermark. Landscape framing, artwork
secondary to application controls, calm and understated.
